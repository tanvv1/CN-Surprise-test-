# BGP Routing Lab – Cisco Packet Tracer

This repository contains the configuration, network topology, and completion write-up for a two-AS eBGP lab (AS 100 / AS 200) completed in Cisco Packet Tracer.

## 📌 Project Overview
- **Autonomous Systems:** AS 100 (Router0) & AS 200 (Router1)
- **eBGP Link:** `203.0.113.0/30`
- **LAN Networks:**
  - AS 100 LAN: `172.16.1.0/24` (PC0, PC1)
  - AS 200 LAN: `172.16.2.0/24` (PC2, PC3)
